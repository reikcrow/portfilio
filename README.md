# Karina Samarets — портфоліо

Статичний сайт на GitHub Pages: https://reikcrow.github.io/portfilio/

Без збірки й залежностей — браузер отримує файли як є. Єдиний інструмент —
Python-скрипт, який готує зображення.

## Як додати роботу

1. Покласти файл у `img/Works/<категорія>/` — теки вже є, назва файлу стає
   назвою роботи (можна кирилицею, з пробілами).
2. `python tools/build-images.py`
3. У `assets/js/data.js` вписати `titleEn` (та за бажанням `blurb`, `blurbEn`,
   `year`, `tool`). Скрипт ці поля не затирає при повторному запуску.

`featured: 1…5` у `data.js` визначає, які п'ять робіт стоять на головній і в
якому порядку. `0` — не показувати там.

## Оригінали не в git

`img/Works/` у `.gitignore`: це 118 МБ, з них одна «Русалка» — 59 МБ. У
репозиторії лежить тільки `img/web/` (1,6 МБ), тобто те, що реально
віддається браузеру. **Репозиторій не є резервною копією вихідних файлів** —
оригінали живуть лише на диску. Щоб класти їх у git, прибери перший блок
із `.gitignore`.

## Локальний перегляд

```
python -m http.server 8000
```

Відкривати саме через сервер, а не подвійним кліком по `index.html`.

## Що де лежить

| Шлях | Що це |
|---|---|
| `assets/js/data.js` | усі роботи: назви, категорії, розміри, розмиті плейсхолдери. Генерується скриптом |
| `assets/js/i18n.js` | усі тексти інтерфейсу українською й англійською |
| `assets/js/site.js` | сітка, фільтр, лайтбокс, перемикач мови |
| `assets/css/site.css` | уся верстка й дизайн-токени |
| `img/web/` | згенеровані WebP: `-1000` для сітки, `-2000` для лайтбокса |

## Нетиповe в коді

- `img/web`, а не `img/works`: на Windows `works` і `Works` — та сама тека, і
  згенеровані файли падали до оригіналів.
- Cormorant за замовчуванням дає мінускульні цифри, тому «2D» і «2006»
  виглядали зламано. Правило з `lnum` стоїть у кінці CSS: шорткат `font:`
  скидає `font-variant-numeric`, і раніше правило не діяло.
- Атрибути `width`/`height` в `<img>` перебивають `aspect-ratio`, якщо не
  задати `height:auto` — звідси це правило в `.frame img`.
